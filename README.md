# WooferWane

A simple WooferWane framework for Multi tenant support.

WooferWane is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- A simple WooferWane framework for Multi tenant support

## Technology Stack

- python
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/WooferWane.git`
2. `cd WooferWane`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
